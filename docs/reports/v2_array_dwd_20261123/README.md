字段映射、单位、业务键、两个时间轴及全部任务入口见 [DWD 说明](../../v2_array_dwd_pit.md)。完整机器汇总见 [summary.json](summary.json)，各表最终证据为 `*_final_audit.json`；带 `initial` 的文件是修正前候选的诊断证据，不代表最终状态。

这次落实的规则包括：研报使用报告日期与源更新时间较晚日期之后的下一 SSE 交易日；基金与股东使用公告后的下一交易日；重复日历行先折叠，缺下一交易日直接失败。基金 `is_complete_holdings` 始终为 NULL。股东业务键纳入报告期、公告日和股东名称；总股东、流通股东两种口径分别保留。主营业务保留分类、币种和源金额，不跨币种求和。CCASS 保留原字符串，同时提供股数与 0～1 比例，无法解析的值不变成零。

独立 Python 用完整 SSE 开市日清单逐组查找严格下一交易日，四张有日期依据的表共覆盖 23,342,973 条记录，错误为 0；没有把“晚于公告日”当作“精确下一交易日”。六张表均检查版本窗口、唯一开放版本、血缘、业务身份、适用的单位/范围和缺失值约束。两张缺披露日的表额外检查可用日必须为 NULL，所有隔离记录的可用日及 `sys_to` 必须为 NULL。

同刻冲突是实际源问题。例如 `000725.SZ` 的 2013Q1，同一公告下同一股东在同一采集批次同时有 275,303,883 股和 277,303,883 股，没有可据以排序的源时间信息。全部冲突原值保留在隔离表；不按哈希、持股量大小、来源优先级或补零选择一方。两类股东具体键和差异见 [holder_conflict_keys.json](holder_conflict_keys.json)。基金隔离涉及 40 个基金、128 只持有股票、177 个业务键。正常和隔离记录合计保留原候选的所有版本行，相关证据见 `*_partition_evidence.json`；基金则从同一份源材料化结果按完整基金历史分片直接产出两份结果。

隔离会减少相关主体/日期的可用覆盖；未来 v2 若改为消费这些正常 DWD，相关研报指标可能变化，不能把覆盖减少解释为零值。本轮没有重建或发布 v2。公开日期 PIT 与系统观察 PIT 分开存储；历史回填不等于恢复了入库之前从未采集过的修订版本。

保留的源限制及告警：

- CCASS、主营业务没有历史公开披露日，不能用持仓日或报告期末代替，也没有用首次入库日冒充历史公开日。
- CCASS 有 10 条非空文本无法转为规范数值：9 条为比例字符串 `nan`，1 条含异常换行文本。原文保留，数值列 NULL。
- 主营业务源另含 `F`（472 行）、`455006000`（2,317 行），总计 2,789 行。保留原分类，未强行映射为 P/D/I；它们本身不是缺披露日的替代证据。
- 研报保留 3 条目标价范围/顺序告警及 10,089 条非标准预测季度文本告警；非标准季度不虚构预测报告期。
- 十大股东原始输入有 2,014 条公告日早于报告期，按有效日期规则排除。其它数量差异还包括重复采集折叠、缺身份过滤及冲突隔离，不能全部归因于日期异常。

基金 RAW 有 **481,865,382 行**，采集时间为 2026-10-13 19:58:06.483 至 2026-11-21 17:14:20.314。一次窗口查询触及 64 GiB 上限，最终改为一次材料化必要源列，并按基金代码分 16 片，每个基金的完整历史位于同片。正常/隔离输出读取同一份稳定输入，`source_table` 仍保留 `fund_portfolio_raw`。材料化耗时 **469.55 秒**、峰值 **0.78 GiB**；32 次正常/隔离分片计算合计 **298.34 秒**，单次峰值 **1.23 GiB**。分片方法已接入正式 `dwd sync`，不依赖手工加内存才能重跑。

研报首次触及 32 GiB 上限，使用 64 GiB 上限及较小读取/压缩块后完成。完整运行及错误日志见 [query_log.json](query_log.json) 与 `runs.jsonl`；共有两次数据库内存失败，均未发布结果。最初候选中的同刻冲突由质量检查拦住，其材料化结果以 `_unresolved` 后缀保留；最终正常表与隔离表的分拆保留了这些输入。基金临时源在所有验收通过、数量和采集边界保存后已清理，正常表、隔离表、初始材料化结果及正式 RAW 均保留。
